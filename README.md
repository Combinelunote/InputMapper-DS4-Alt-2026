# InputMapper DS4 Windows Setup Notes

## Download & Install

> Setup notes for **InputMapper DS4** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Complete activation in the installer if required
5. Restart if the installer asks — then launch **InputMapper DS4** from the Start menu

## What you can use it for

- Core InputMapper DS4 features on Windows desktop
- Install and configure InputMapper DS4 for daily use
- Import, edit, and export with InputMapper DS4 tools
- Tune settings and profiles inside InputMapper DS4
- Integrate InputMapper DS4 into your existing workflow
